## 3. Правило синхронизации деревьев: прод → Astro, никогда наоборот

Это главное. В репозитории два дерева, и по объёму контента они расходятся.
Направление легко прочитать наоборот, и цена ошибки — потеря живого контента.

Замер одним методом (`tools/duplicate-audit.py` для прозы секций):

| | Секций | Слов всего | Проза секций |
|---|---|---|---|
| **`deploy/` (прод)** | **11** | 1218–1692 | 822–1293 |
| `site/src/data` (Astro) | 8 | 641–868 | 417–635 |

Прод **длиннее**, а не короче. Диапазон «650–870 слов» — это Astro-порт;
если он попался как «прод», значит метки в замере поменялись местами.

Прод содержит три секции, которых в порте нет: «Премиум-окружение»,
«Что знать» и объектный блок. На примере Дома Перцовой:

```
ПРОД  : Геро | История | Архитектура | Премиум-окружение | Типология |
        Голос эксперта | Что знать | FAQ | CTA | Связанные | Карта
Astro : Геро | История | Архитектура | Типология | Голос эксперта |
        FAQ | CTA | Связанные
```

**Почему так.** История git однозначна: обе версии созданы 7 июля, тонкие
пришли из ветки `seo-qa-canon-fixes`, а прод-версии были дописаны при переносе
(коммит «Перенос правок Серёги — 10 страниц авангарда»). Обратно в `site/`
это дописывание не вернулось. Это не сокращение и не сбой конвейера.

**Следствие.** Копирование `site/` → `deploy/` сотрёт на десяти живых страницах
около 40% контента и три секции целиком, включая «Что знать» — блок, который
несёт E-E-A-T на теме, где на кону деньги и право собственности.

Служебная часть уже синхронизирована в правильную сторону (`tools/fix-site-tree.py`):
canonical переведён на живые `/modernizm/`, восстановлен тип
`LandmarkOrHistoricalBuilding`, снят неподтверждаемый рейтинг «РГР Топ-N».
Контент в `site/` намеренно не переносился: дерево в прод не собирается,
и трогать его без решения владельца смысла нет.

Проверить расхождение в любой момент:

```bash
python tools/tree-diff.py --mode report \
  --phrase-forbid "РГР Топ-3" --phrase-forbid "РГР Топ-4"
```

## 4. Состояние после слияния

Шесть гейтов на объединённой ветке — чисто:

```bash
python tools/test_pages.py deploy          # 0 CRIT
python tools/test_pages.py site/src/data   # 0 CRIT
python tools/qa-lint.py A                  # 0 находок
python tools/qa-lint.py B                  # 0 находок
python tools/map-audit.py deploy           # 0 CRIT  (было 11)
python tools/map-audit.py site/src/data    # 0 CRIT
python tools/board.py                      # доска состояния раздела
```

`tools/board.py` собирает `_qa/board.html` — таблицу по всем 19 страницам
раздела плюс сводку гейтов. Красных ячеек нет.

Что закрыто по созвону 20.07: семь зданий, названных Володей поимённо;
карты (11 расхождений → 0, включая пример с Моссельпромом, где были неверны
обе координаты); счётчики хаба сведены к одному числу; «Районы» вместо «ЦАО»;
19 из 19 страниц прошиты в хаб — раньше семь были недостижимы кликом,
включая две старые, Дом писателей и Дом полярников.
